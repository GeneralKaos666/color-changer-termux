# Rebrand to `termux-settings` and unify the UI — design

Date: 2026-10-25
Status: draft (awaiting review)

## Goal

Rebrand the app from `termux-colors` to **`termux-settings`** (repo, binary,
crate, package) at **version 1.0.0**, and give every user-facing screen one
coherent, "futuristic" look borrowed from the Go `font-changer` picker: a
gradient title, a fixed violet accent, rounded panes with left-aligned titles,
dotted rules, and a context-sensitive help bar.

## Success criteria

- One name everywhere: `termux-settings` (binary/package), `termux_settings`
  (Rust crate), repo renamed to `GeneralKaos666/termux-settings`. Version
  `1.0.0`.
- Every reachable screen shares the same visual frame, so the app reads as one
  product rather than a collection of hand-rolled screens.
- The live re-theming feature survives: content text and background still
  follow the active terminal palette; only the *chrome* (accent, title
  gradient, borders) is fixed violet.
- `--ascii` (and `TERMUX_SETTINGS_ASCII`) swaps every glyph for a plain-ASCII
  equivalent, with the old env vars honoured as deprecated fallbacks.
- Existing on-disk formats, backup naming, and `colors.sh` interoperability are
  unchanged.

## Non-goals

- **No navigation restructure.** The drill-down menu (`Preset Themes` /
  `Terminal Colors` / `App Theme` / `Fonts`) stays. The tab-bar idea from
  `2026-10-24-merge-font-changer-design.md` is deliberately not revisited here.
- No change to config file formats or backup behaviour.
- No change to the font subsystem's logic (scan/apply/import/download) — only
  its screen's chrome.
- No new language runtime or dependency; the design uses ratatui styling
  primitives and the existing `theme::blend`.

## 2. Chrome design system

A small fixed-chrome layer that does **not** move when the terminal palette
changes. Content (background, foreground, previews, swatches) still follows the
palette.

### 2.1 Accent

- `accent` = `#5B50E6` (indigo) on light backgrounds, `#A49EFF` (violet) on
  dark backgrounds — chosen by `palette.dark`.
- Used for: pane borders, selection background, badges/chips, help-bar key
  hints, the `▶` marker, and the dialog focus button.

### 2.2 Gradient title

- The app name is rendered bold with a two-stop gradient `#C9C2FF` (lavender)
  → `#5B50E6` (indigo), per character via `theme::blend` (the same maths the
  Go `gradientTitle`/`blendHex` use).
- On light backgrounds, the dark stop is deepened with `ensure_contrast` so the
  title stays legible.

### 2.3 Panes

- Rounded borders, title embedded **left-aligned** in the top border
  (`╭─ Themes (12) ────╮`), border colour = accent.
- Replaces every `Block::bordered().title(...)` that is currently
  centre-aligned.

### 2.4 Selection

- Selected list row = accent background + white foreground + `▶ ` marker
  (was `› `).
- Focused form field keeps its accent treatment, restyled to the same accent.

### 2.5 Rules

- Section separators use `┄` (dotted) instead of `─`.

### 2.6 Help bar

- One global footer (drawn by `App`), always visible, replacing each screen's
  inline hint line and the terminal editor's button row.
- Format: accent-coloured key hints + muted descriptions, joined by ` · `.
- Each screen exposes its hints via a shared trait method
  (`fn help(&self) -> Vec<(&'static str, &'static str)>`), so the footer is
  context-sensitive.

### 2.7 Glyphs and `--ascii` fallback

A single glyph provider resolves every special character, so `--ascii` (and the
env var) swaps them consistently:

| Meaning | Unicode | ASCII |
| --- | --- | --- |
| selection marker | `▶ ` | `> ` |
| dotted rule | `┄` | `-` |
| slot/badge chip | `⟨ ⟩` | `< >` |
| active badge dot | `●` | `*` |
| ellipsis | `…` | `...` |
| filter glyph | `⌕ ` | `? ` |

`ui::ascii` becomes the source of truth for the mode; a new
`ui::glyphs` helper exposes the resolved characters.

## 3. Shared frame and per-screen changes

`App::render` lays out a consistent frame on every screen:

```
╭─ termux-settings › Section ───────────────────────────╮   header (gradient title + breadcrumb)
│                                                        │
│                        (screen body)                   │
│                                                        │
├────────────────────────────────────────────────────────┤
│  ↑/↓ move · Enter open · Tab focus · Esc back · q quit │   help bar
└────────────────────────────────────────────────────────┘
```

- **Header** — gradient `termux-settings` + breadcrumb (the current section),
  shown on **all** screens. On the main menu the header shows only the gradient
  title (no breadcrumb, since there is no section). Today the menu has no
  header at all.
- **Main menu** — gradient title, palette strip + active-theme line kept as the
  hero, menu box restyled to the pane style, help bar replaces the inline hint.
- **Preset Themes** — list + preview panes restyled (left titles, `▶` marker,
  `● active` badge), dotted rule in the preview, help bar.
- **Terminal Colors** — form + preview panes restyled, dotted section rules,
  focused-field accent, action row (`ctrl+s`/`ctrl+a`/`ctrl+r`) folded into the
  help bar.
- **App Theme** — same frame as Terminal Colors (its editor form + save flow is
  already shared).
- **Fonts** — preview + list panes restyled, `⟨ slot ⟩` chip, help bar replaces
  the `[s]lot [p]review…` line.
- **Dialogs** — accent border, left-aligned title, accent focus button; body
  text unchanged.
- **"terminal too small" notice** — kept, restyled with the accent.

## 4. Remove dead screens

`ColorsTab` and `AppThemeTab` are unreachable (the main menu pushes

- Delete `src/screens/colors_tab.rs` and `src/screens/app_theme_tab.rs`.
- Remove their `ScreenKind` variants, `Screen` variants, and all `match` arms
  in `screens/mod.rs`.
- Drop any `tests/` coverage that references them.

## 5. Testing

Keep the existing pattern: inline unit tests and `tests/` integration tests via
`support/mod.rs` (`TestBackend`, `Paths::new(tempdir)`), hermetic throughout.

- **Rename**: update `use termux_settings::` and the two header-string
  assertions.
- **Glyph provider**: unit tests assert the Unicode/ASCII pairs above.
- **Gradient title**: unit test that it emits one span per character and that
  the two end stops match the lavender/indigo constants.
- **Help bar**: integration tests assert each screen's footer renders the
  expected hints and that the footer changes with focus (e.g. the preset
  picker's filter vs list).
- **Removed screens**: delete any tests that reference `ColorsTab`/`AppThemeTab`.
- Existing behaviour tests (save/backup/roundtrip/font flows) must stay green
  unchanged.
