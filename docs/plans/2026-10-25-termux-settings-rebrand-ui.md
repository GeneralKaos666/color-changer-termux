# termux-settings rebrand + UI unification — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the app to `termux-settings` (v1.0.0) and give every user-facing screen one coherent, futuristic look (gradient title, fixed violet accent, rounded left-titled panes, dotted rules, context help bar).

**Architecture:** A small fixed "chrome" layer (`chrome.rs` accent + gradient, `ui/glyphs.rs` ASCII-aware glyphs) sits beside the existing palette-derived `Palette`. `App` draws a shared header + help bar around every screen; each screen drops its inline hint/action row and instead reports its key bindings via a new `help()` method dispatched through the `Screen` enum. Screens then restyle to use the chrome accent, `▶` selection, and left-titled panes.

**Tech Stack:** Rust (edition 2024, rust 1.85), ratatui 0.29, crossterm 0.28. No new dependencies.

**Spec:** `docs/specs/2026-10-25-termux-settings-rebrand-ui-design.md`

## Global Constraints

- Binary/package name: `termux-settings`; crate name: `termux_settings`; version `1.0.0`.
- Env var `TERMUX_SETTINGS_ASCII` (with `TERMUX_COLORS_ASCII` and `FONT_CHANGER_ASCII` read as deprecated fallbacks).
- Fixed accent: `#5B50E6` on light backgrounds, `#A49EFF` on dark (chosen by `palette.dark`).
- Gradient title stops: `#C9C2FF` → `#5B50E6`; dark stop deepened via `theme::ensure_contrast` on light backgrounds.
- Selection: accent background + white foreground + `▶ ` marker (`> ` in `--ascii`).
- Dotted rule glyph `┄` (`-` in `--ascii`); badge dot `●` (`*`); chip `⟨ ⟩` (`< >`); ellipsis `…` (`...`).
- Config-file headers `# Generated by termux-settings` / `# Termux properties managed by termux-settings`; parsers never read them.
- No navigation restructure (menu → screens stays). No on-disk format or backup change.
- Every commit GPG-signed (`-S`), verified `G`.

## Review Focus

1. **Accent flips with background.** A dark theme must get `#A49EFF` borders, a light theme `#5B50E6`, or chrome is invisible on one of them. → Task 3 unit test.
2. **`--ascii` degrades every glyph.** With `set_ascii(true)`, no Unicode box/marker glyph may appear. → Task 3 glyph unit tests (one assertion per glyph pair); each restyle task routes every glyph through `ui::glyphs`.
3. **Gradient title stays legible on light backgrounds.** The indigo stop is deepened so the title reads against a near-white background. → Task 3 unit test.
4. **Header + footer shrink the content area.** At the 40×10 floor the menu must still show its items (or the too-small notice), not clip silently. → Task 4 render test at small size.
5. **Status message replaces the help bar cleanly.** An active status must not overlap or double-render against the footer. → Task 4 render test.
6. **Old-version config files still parse.** A file with a `# Generated by termux-colors` header (written pre-rename) must load unchanged, because parsers key off `background=` etc., never the header. → Task 1 test.
